# Análise de Dados do Brasileirão

## Objetivo

Este projeto tem como objetivo realizar uma análise exploratória de dados do Campeonato Brasileiro utilizando Python.

Através dos dados das partidas, serão analisadas estatísticas como:
- desempenho dos times;
- gols marcados e sofridos;
- vantagem de jogar em casa;
- padrões e tendências ao longo das temporadas.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Git
